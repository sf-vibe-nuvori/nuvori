# model/PARAMETERS.md — 엔진 ↔ 시뮬레이션 파라미터 대조

`hsmm-engine.js`(배포용 경량 엔진)와 `simulation/hhmm_pomdp_simulation.py`(300가구 × 365일 몬테카를로 검증)의
파라미터 일치/불일치를 기록한 문서다. **불일치는 기록만 하고 수정하지 않는다** (루트 CLAUDE.md 경계 규칙).
기준 시점: 2026-11-25, `feat/model` 브랜치.

상태 인덱스 주의: 엔진은 `{pSurplus, pNormal, pDepleted}` (S2→S1→S0 순서 개념), 시뮬레이션 벡터는 `[S0, S1, S2]`
(index 0 = Depleted). 순서 표기는 다르지만 의미론은 동일하다.

| 항목 | 엔진 (`hsmm-engine.js`) | 시뮬레이션 (`hhmm_pomdp_simulation.py`) | 비고 |
|---|---|---|---|
| 상태 구조 | S2(Surplus)→S1(Normal)→S0(Depleted) 3-상태 | 동일 3-상태 (`quantity_to_state`) | 일치 |

| 소진 상태의 흡수성 | S0는 질량을 잃지 않음 (`nextS0 = bS0 + …`) | T의 S0→S0 (단, 미세 leak 있음 — §2 참조) | 대체로 일치 |
| 연령 의존 hazard 개념 | hazard가 경과일에 따라 증가 | `build_hsmm_age_transition` — 경과 의존 | 개념 일치 (식 형태는 §2) |

## 2. 불일치 항목 (기록, 수정 없음)

### 2.1 상위/하위 위상 분할 비율
- 엔진: `halfCycle = max(1, 0.45·cycleDays)`, `remCycle = max(1, 0.55·cycleDays)` → **45/55** 분할
- 시뮬: `d2 = max(1.2, 0.47·E)`, `d1 = max(1.2, 0.53·E)` → **47/53** 분할, 하한 **1.2** (엔진은 1)

### 2.2 hazard 클램프 범위
- 엔진: h21 ∈ [0.05, 0.85], h10 ∈ [0.04, **0.90**]
- 시뮬: h21, h10 ∈ [**0.005**, 0.85] — 하한이 엔진보다 10배 낮고 h10 상한이 0.85로 낮다

### 2.3 hazard 함수 형태
- 엔진: `h21 = (1/halfCycle)·(1 + 0.35·d/halfCycle)` (선형 증가), `h10 = (1/remCycle)·(max(0.2, d/c))^1.6` (거듭제곱)
- 시뮬: 정규분포 CDF(erf) 기반 `state_probs_at_day`에서 유도된 경과 의존 전이. 형태 자체가 다른 함수족이며
  수치 직접 비교 불가. 둘 다 "경과가 길수록 전이 확률 증가"를 부호화한다.

### 2.4 일일 no-purchase 우도(방출)
- 엔진: 매일 고정 `[0.98, 0.98, 0.72]` — S0가 매우 강하게 페널티. 장보기 요일 개념 없음.
- 시뮬: 장보기 요일(7일 주기)에만 범주별 방출 `[prob_buy_when_depleted, prob_impulse_buy_normal, 0.005]`,
  비장보기일 `[0.01, 0.001, 0.0002]`. 범주·요일 의존. **가장 큰 구조적 불일치.**

### 2.5 S0→S1 미세 회복 leak
- 엔진: S0 완전 흡수 (회복 없음)
- 시뮬: `T[0] = [0.998, 0.002, 0]` — 하루 0.2% 확률로 S0→S1 회복 leak

### 2.6 품목별 소비주기 수치
| 품목 | 엔진 (`inferCycleDaysByName`) | 시뮬 카테고리 mean | 판정 |
|---|---|---|---|
| 우유 | 8 | fast_staple 10.5 | 불일치 |
| 계란/달걀 | 12 | fast_staple 10.5 | 불일치 |
| 파스타·라면 | 21 | med_staple 24.0 | 불일치 |
| 양파 | 12 (계란·감자 티어) | med_staple 24.0 | **불일치** (티어 배치 자체가 다름) |
| 간장·식용유·올리브 | 60 | slow_condiment 60.0 | 일치 |
| 마른오징어·코코넛밀크 | 기본값 10 (미등록) | episodic 42.0 | 불일치 (엔진에 episodic 티어 없음) |
| 기본값 | 10 (미등록 품목) | 해당 없음 | — |

### 2.7 구매 판정 임계값
- 엔진: `isShort` — pDepleted ≥ **0.24 고정** 또는 경과 ≥ round(**0.75**·cycleDays)
- 시뮬 (Method 4, Newsvendor 비대칭 손실): `thresh = overbuy/(stockout+overbuy)` —
  fast 0.123, med 0.122, slow 0.118, episodic 0.250 (범주별 가변).
  엔진의 고정 0.24는 episodic의 0.25와만 유사. POMDP 연령 리셋은 `0.72·est` (엔진 0.75와 근사 불일치).

### 2.8 Empirical Bayes 주기 갱신
- 엔진 (`updateCycleDays`, 신규 추가): `0.7·prev + 0.3·interval` 고정 가중 블렌드.
  유효 간격 [2, 90]일 밖이면 prev 유지, prev는 최소 2로 클램프.
- 시뮬: 공액식 `est = (2·prior_mean + n·sample_mean)/(2+n)` — 관측 횟수 n에 따라 가중치가 변함.
  관측치는 `max(2, interval − cum_s0_days)`이고 상한 `2.5·mean` 캡.
  또한 `est_cv = max(0.12, cv/√(1+0.7·n))`로 CV를 감소시킴 (엔진은 CV 개념 자체가 없음).
  ※ 양쪽에 0.7이 등장하지만 역할이 다름 (엔진: 블렌드 가중치 / 시뮬: CV 감쇠 계수).

### 2.9 소비량 노이즈 모델
- 엔진: 없음 — 결정론적 hazard 전파만 (배포용 경량화)
- 시뮬: 로그정규 가구 이질성(`cv_household`), 일별 가우시안 노이즈(`daily_noise_cv`),
  3% 확률 ×2.4 소비 쇼크, 수량 상태 임계 (Surplus >60%, Normal 15–60%, Depleted ≤15%)

## 3. 엔진 단독 특성 (테스트로 확인된, 변경하면 안 되는 동작)

테스트 스위트 (`model/tests/run-tests.js`) 검증 중 발견한 사실을 기록한다:

1. **단조성의 유효 범위**: 일 단위 엄격 단조성(elapsed↑ → pDepleted 비감소)은 **경과 0 ~ 3×주기** 구간에서
   주기 1~90일 전 범위에 대해 성립. 그보다 먼 꼬리(경과 ≳ 3.4×주기, 주기 45일 이상)에서는 매일 재정규화의
   고정점 때문에 계단형 미세 감소(일별 <~0.03)가 존재한다. 단 3c ≤ 4c ≤ 6c 지점 간 대소 관계는 유지된다.
2. **isShort 두 규칙의 선후 관계**: 주기 1~90일 전 범위에서 경과 규칙(round(0.75·cycleDays))이
   pDepleted ≥ 0.24 도달보다 항상 먼저(또는 동시에) 발화한다. 즉 실사용 범위에서 0.24 임계는 예비 안전장치 역할.
3. **elapsed=1 특이점**: d=1에는 S1 질량이 0이라 h10이 작동하지 않아 pDepleted=0 (소진 질량은 d≥2부터 생성).
4. **경과 0 / 음수 경과**: 전파 루프 미실행 → 초기 신념 {1, 0, 0} 그대로 반환.

## 4. 결론

엔진은 시뮬레이션의 Method 3(HSMM MAP)을 단일 품목·경량 형태로 근사한 구현으로, **개념 구조(3-상태,
S2→S1→S0, 연령 의존 hazard, 구매 관측 갱신)는 일치**하나 **수치 파라미터 대부분은 의도적 차이**를 둔다
(2.1~2.9). 계약(`contracts/`) 변경은 불필요 — `updateCycleDays` 추가는 엔진 내부 API 확장이며
`inventory-state` 스키마의 `cycleDays` 필드 정의에 영향을 주지 않는다.
